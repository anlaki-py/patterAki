# PatternAki

Local-first sewing-pattern drafting, built from the two supplied specifications. This is the first implementation increment, not the complete v1 product.

## Run

Requires Node.js 22.12+ and npm. No environment variables or backend are needed.

```sh
npm ci
npm run dev
```

Open `https://localhost:5173/` on the development machine, or `https://<server-LAN-IP>:5173/` from another device on the same network. The dev server binds to all interfaces and uses HTTPS with an automatically generated, cached self-signed certificate from `@vitejs/plugin-basic-ssl`. Accept the development certificate warning on each device for this server. If your browser/device policy blocks self-signed certificates, use a locally trusted certificate instead. Restart `npm run dev` if an existing server has not picked up the HTTPS configuration. Port 5173 must be free; Vite will fail rather than silently switch ports.

Use `https://`, not the old `http://` address. HTTP, HTTPS, localhost and LAN IPs are separate browser storage origins. A project saved at `http://localhost:5173/` will not automatically appear at the new HTTPS address. To recover it, temporarily disable `basicSsl()` in `vite.config.ts` and restart the dev server, export JSON on the old origin, and import it on HTTPS. Do not clear browser storage when switching origins.

The ID generator supports ordinary HTTP LAN origins too: browsers can omit `crypto.randomUUID` there, so it falls back to random bytes from `crypto.getRandomValues`. This avoids an exception during store initialization and supports subsequent drawing operations. HTTPS remains the default for development and is required for future PWA features.

Production output is a static site in `dist/`, generated by `npm run build`. Production hosting must supply its own trusted HTTPS certificate; the development certificate is not part of the app bundle.

## Available now

- Shared command registry for implemented menu, toolbar, context-menu, inspector, dialog and shortcut actions, with stable IDs, labels, shortcut hints and availability checked again on execution. Existing tool keys are preserved.
- Mantine editor shell, light/dark mode, hidden-by-default Properties panel that toggles a resizable desktop inspector or mobile drawer, Lucide tools.
- Millimetre coordinates with cm default display; mm/cm/in selection does not rescale geometry.
- Straight click-to-create Line and Polyline segments, close a polyline at its first point, and numerically sized rectangles. Use Curve (C) explicitly to bend an edge after placement. A closed polyline is currently a drafting path, not a garment piece.
- Live line length/angle, explicit length/angle entry, endpoint, midpoint, live intersection, on-edge, guide, guide-intersection, 45°, perpendicular and alignment snapping through one deterministic resolver. Grid snapping has a subtle cross marker and a `Grid` status label instead of the prominent ring used for exact geometry. Idle Select/Pan movement shows no snap overlays.
- Shift-click multi-selection, box selection, Ctrl/Cmd+A, direct edge/group dragging with previews and batch delete/curve reset. Select edges, drag their endpoints with a preview, edit length with Start/Center/End fixed, Add point (X) tool with edge placement preview, split by double-click or exact distance, delete edges, undo/redo.
- Horizontal and vertical rulers plus persistent construction guides. Drag a guide from either ruler, or use exact mm position/offset controls for touch and keyboard use. Guides can be selected, locked, hidden, deleted and exported in project JSON; the ruler overlay never changes the document transform.
- Snap settings for grid spacing, major interval, per-type snap modes, mouse/touch pickup radii, release multiplier, ruler/guide visibility, guide snapping and nudge step. Settings persist locally in IndexedDB and never create document undo entries.
- Movement snapping for individual vertices, selected edges, multi-edge groups and mixed selections, with applied delta preview, Shift axis lock, Alt bypass, exact Move… dialog and Arrow/Shift+Arrow/Alt+Arrow nudging.
- Pattern marks: editable multiline text, arrows, grainlines, fold guides and drill-point crosses, with physical sizes, rotation, selection, dragging and undo.
- Debounced IndexedDB saving, restoration of the latest project, manual save, validated JSON import, lossless JSON export. Import creates a new project ID to preserve the saved source.

Click a rectangle origin, enter `18` and `24` with cm display, then Create rectangle to create a 180 × 240 mm drafting outline. Select a line and use its length field to try each anchor. Enter applies the length preview; Escape cancels it. Polyline Finish commits the entire path as one undo step.

Snapping follows existing straight or curved edges, their endpoints and their midpoints. A curve midpoint is half its arc length. While drawing, dashed guides align the pointer horizontally or vertically with existing points at any distance, and an active origin adds optional 45° rays and perpendicular feet on finite straight edges. Exact topology wins in this order: endpoint, existing intersection, guide/guide or guide/edge intersection, midpoint, perpendicular, aligned-on-edge, on-edge/guide, horizontal/vertical alignment, 45°, then grid. Nearby grid points can still be acquired when nothing stronger is within the pickup radius. A held target stays selected through 1.5× the pickup radius, but a newly near exact endpoint or intersection can replace a weaker held grid/alignment target. Two or more eligible targets at the same priority show `1 of N`; Tab/Shift+Tab cycles them while a placement preview is active, and the `Choose target` menu provides the same list without a keyboard. Cycling is transient and does not create geometry or history. Potential ambiguity remains on touch: because hover is unavailable, the first tap can commit the default candidate before the chooser is usable.

An `Intersection` snap follows a crossing of two existing line/line, line/cubic or cubic/cubic segments while drawing or moving a point; the marker appears before the click, and both the preview and the committed point use the solver's exact millimetre coordinate. This transient snap does not split or weld either edge—`Create points at intersections` remains the separate command that does that—and Add point inserts on only the one edge chosen by the snap. Add point uses the same preview to commit and can align a point on an edge with a distant reference. Guide snaps project to visible guides, exact guide/guide crossings, and guide crossings with finite straight or curved edges; a parallel guide and edge with an overlapping interval do not fabricate a unique intersection. Hidden guides and the `Snap to guides` switch disable guide acquisition. Alt or Snap off disables magnetic snapping; the status bar reports `Snapping temporarily off` or `Snap off`. Add point still stays on an edge, and a Shift direction constraint still applies because it is not magnetic snapping. Typed exact dimensions take priority. Alignment and 45° guides are temporary and are not saved; construction guides are separate persistent document items.

Properties starts hidden. Click Properties to show or hide it. To insert a vertex, choose Add point in the toolbar or press X, then click an existing edge. The tool remains active for repeated insertions; clicks on empty space or existing endpoints do not create points. Right-click any edge to open its action menu. Choose Point at exact distance to open the draggable measurement window. Edit From A or From B; the other distance updates so the outer endpoints stay fixed. The canvas marks A/B and previews the point. Drag the title to move the window, or focus its title and use arrow keys. Enter applies one undoable edit; Escape or Cancel discards the preview. Right-click an already inserted point on a straight edge and choose Point at exact distance to adjust its position between its neighbours. Corners, branch points and existing vertices between curves are not repositioned by this dialog; use point/handle dragging. Inserting inside a curve uses true arc distance from each end. The Point at exact distance button provides access without right-click, using the last canvas position. Properties also retains its distance-from-start input.

In Select mode (V), click an edge and drag it to move it. Shift-click adds or removes edges; dragging any selected edge moves the whole selection. Clicking an unselected edge replaces the selection. Drag empty space to draw a selection box; every line or curve touching or crossing the box is selected on release, even when both endpoints are outside. Touching a border or corner counts; an overlapping bounding box alone does not. Drag in either direction, or hold Shift when starting the box to add to the existing selection. Click empty space to clear the selection. Ctrl/Cmd+A, or Edit → Select all, selects every edge and mark and switches to Select. These selection changes do not enter document history.

Right-click a selected edge to keep the group and apply Delete selected edges or Reset selected curves / remove handles to all of it. Right-click an unselected edge targets that edge alone. Edge actions provides the same commands without right-click. Delete/Backspace also deletes the selection. Change length, exact point placement and intersection actions require a single edge. A group shows highlighted strokes without individual point/curve handles; select one edge to reshape its endpoints or controls.

Edge/group and vertex movement previews a translation or moved vertex with live delta X/Y, preserving relative positions and curve shapes. The preview is computed from eligible stationary geometry, excluding the moving points and incident/selected edges, and the displayed delta is the applied snapped delta rather than the raw pointer delta. Shift locks the dominant axis after the 3 px drag threshold and holds it until Shift is released; candidates off that axis are rejected. Alt temporarily bypasses movement snapping. Shared vertices move once and stay connected; unselected neighbours attached to them reshape, with their attached controls following. Release commits one undo step. Escape, pointer cancellation or loss of pointer capture cancels the move; invalid contours and moves that collapse a neighbour or exceed the coordinate range leave the original geometry intact. A click or slight pointer jitter makes no geometry edit. Batch deletion and curve reset also each undo in one step.

Use Move… in Properties or the command menu for exact ΔX/ΔY translation in the current display units, including negative and decimal values; Apply commits one history entry and Cancel restores the original. Arrow nudges by the configured step (default 1 mm), Shift+Arrow by 10× and Alt+Arrow by 0.1×. A keypress is one undo entry, and nudges are blocked while typing, while the Move dialog is open, during a pointer gesture, or while a draft/preview is active.

`Snap settings` in the viewport toolbar controls magnetic snapping, grid visibility versus grid snapping, grid spacing and major interval, every snap type, mouse/touch pickup, the release multiplier, ruler/guide visibility and guide snapping, and the nudge step. Settings are validated, persisted locally in IndexedDB and applied without resetting the current tool or document. The rendered minor/major grid follows the physical mm spacing but hides overly dense minor lines at extreme zoom; logical grid snapping keeps the configured spacing.

Rulers appear along the top and left of the canvas without shifting the drawing. Hide them with `Show rulers`. Drag from the top ruler to create a horizontal guide or from the left ruler to create a vertical guide; the preview is discarded on Escape or pointer cancel and only release inside the drawing area commits one undo entry. Turn on `Edit guides` to drag an unlocked guide; locked guides stay fixed but remain available for snapping. Properties lists every guide and provides exact position, mm offset, lock, visibility and delete actions, plus numeric vertical/horizontal creation. `Show guides` controls the overlay, while `Snap to guides` controls magnetic eligibility; individual hidden guides never snap. Guide positions and visibility survive save/reopen and JSON export/import.

The edge menu includes Change length for straight edges, Point at exact distance, Create points at intersections, Convert to curve or Convert to straight / remove handles, and Delete edge. Change length opens a draggable window with the Start/Center/End anchor controls. Drag its title to reposition it, or focus the title and use arrow keys. It stays within the viewport and opens at its default position each time. For a single selection, Reset curve straightens only that segment and removes its control handles; it does not delete neighbouring anchor points. All edits are undoable. The Edge actions button provides the same commands for the current selection without right-click.

Right-click empty space to add **Text / piece label**, **Arrow**, **Grainline**, **Place on fold guide**, or **Drill point / cross** at that position. The **Marks** button provides the same choices at the last canvas pointer position, plus Edit/Delete for a single selected mark. The editor opens as a draggable window with a live preview. Text supports multiple lines, up to 1000 characters, and an editable size. Use labels for piece names, sizes, material, cut quantities such as “Cut 2 mirrored”, or notes. Arrows and grainlines have editable length, clockwise angle and an optional label. Grainlines have arrowheads at both ends; fold guides are dashed with end bars. Drill points show a circle and cross with an editable diameter.

Text size, arrow length and mark diameter use the current display unit and store millimetres. Text uses a fixed-width layout so its selectable area and physical size are consistent through zoom and save/reopen. Rotation is clockwise from the horizontal. Apply commits one edit; Escape or Cancel discards the preview. Enter applies from numeric fields; in multiline text, Enter adds a line and Ctrl/Cmd+Enter applies. Double-click a mark, press Enter with one selected, right-click → Edit mark, or use Marks → Edit mark to reopen its controls. Drag marks in Select mode; Shift-click, crossing-box selection, Ctrl/Cmd+A and Delete work with marks and mixed edge/mark groups. Fit all includes marks. Each move or batch delete is one undo step, and mark-only edits preserve fabric geometry.

Free marks remain independent visual annotations. M2.2 adds optional piece-/edge-attached grainlines and fold marks, attached notches, dart objects and sewing roles through Properties. Exported JSON uses schema version 9. Versions 1–8 are validated before migration on import/open; the original stored record is not rewritten until the next save.

Create points at intersections checks the clicked edge against other document edges, splits every participating edge and shares the crossing vertex. It supports line/line, line/cubic and cubic/cubic crossings and endpoint touches. Repeating it does not add duplicate points. Cubic intersection positions are refined numerically, with endpoint welding within 0.0001 mm; overlapping/coincident edges and unresolved close curves report an error without committing partial edits. Self-crossings within a single cubic are not included. Very close crossings within the welding tolerance are treated as one node.

To curve an edge, choose Curve (C), then drag the edge. A click converts it to a straight-shaped cubic with visible arms. Drag either arm to adjust curvature. A point joining two segments shows an arm for each adjacent segment; an open endpoint has one arm. Corner arms are independent. Smooth links tangent directions; Symmetric also links lengths. Hold Alt to decouple temporarily. Moving an endpoint carries its attached controls. Properties shows actual arc length and chord separately, supports insertion by arc distance, and offers Convert to straight / remove handles. Adding a point to a cubic preserves its shape through de Casteljau splitting. Curve editing is a single undo transaction; Escape cancels the preview.

Arc lengths use adaptive subdivision with a 0.001 mm error budget and a depth limit of 24. Curve intersection refinement tolerates parameter roundoff at shared endpoints, preventing normal corner bends from being falsely flagged as microscopic crossings. Real interior crossings and overlaps remain invalid. Curve hit testing uses adaptive subdivision and local parameter refinement. Closed contours are checked for nonadjacent line/cubic or cubic/cubic crossings, overlaps, self-touching, zero-length edits and single-cubic self-crossings. Validation runs before a closed draft commits and before a vertex/group/curve move, length edit, numeric move or nudge commits. An invalid preview is drawn in red and the whole operation is rejected rather than partially applied. Only unambiguous simple cycles and explicitly closed drafts are treated as closed contours, so open construction lines and two separate intersecting contours are not misclassified. Ambiguous or branched topology produces a warning instead of certifying the edit. Linked smooth handles and perpendicular snapping to curved edges remain pending. Measurements display at most two decimal places without rounding canonical geometry.

Keyboard: V select, C curve, X add point, L line, P polyline, R rectangle, H pan, Space+drag temporary pan, Ctrl/Cmd+A select all, Ctrl/Cmd+Z undo, Ctrl/Cmd+Shift+Z redo, Ctrl/Cmd+S save. Tab/Shift+Tab cycle same-priority snap choices only while a placement preview is active and focus is not in an input, dialog or menu. Arrow nudges by the configured step; Shift+Arrow and Alt+Arrow use 10× and 0.1×. Alt temporarily bypasses magnetic snapping during a pointer gesture. Shortcuts do not run inside inputs or dialogs. Draft Backspace/Delete removes the last draft point. Escape cancels the current gesture/draft; another Escape returns to Select.

Export JSON regularly. Browser storage is local to this browser and can be evicted. Automatic saves contain committed geometry only. Use one editing tab per project; cross-tab conflict detection is pending. New project saves the previous project; a project browser for reopening older records is still pending.

## Live dimensions and numeric editing (M1.2)

Selected edges and changed neighbors show live lengths and chord directions. A vertex move shows before/after values and ΔX/ΔY; group and piece movement shows the applied translation. The overlay prioritizes the selected edge and limits affected labels to six. Curves distinguish arc length from chord length. Escape restores the original geometry; a committed gesture creates one undo entry.

Click or tap a dimension, or press Enter with one edge selected, to open its focused length window even when Properties is hidden. Straight edges support Start / Center / End anchors, with A/B labels on the canvas. The last anchor is remembered for the current app session, including after cancelling or switching projects; it is always displayed. Shared vertices and attached curve controls follow length changes. Curve dimensions open a read-only arc-length control and curve tools; setting an exact arc length remains unsupported.

Length, draft width/height, exact split-distance, division-spacing and Move fields accept explicit `125 mm`, `12.5 cm` or `1 in`. Bare numbers use the current display unit. Decimal points and scientific notation are supported; ambiguous separators, unknown suffixes and nonfinite values are rejected. Display labels use at most two decimal places; input parsing does not round the canonical millimetres. These fields use Mantine text inputs because NumberInput strips unit letters; angle, percentage and count controls remain NumberInput.

After placing a line/polyline origin, type a number, press Enter, or click its dimension to focus exact entry. The field initially uses the preview direction, and the angle remains editable. Typed dimensions override magnetic snapping and update the ghost endpoint. Enter in a field adds the exact segment and returns focus to the canvas. For a polyline, this adds a draft point; Enter on the canvas or Finish commits the whole path once. Double-clicking the last endpoint finishes without adding a duplicate. Escape cancels the entire unfinished draft. Rectangle dimensions also preview and accept Enter to commit.

Add point hover shows distances from A and to B plus the percentage, using true arc distances on curves. Edge actions and the context menu offer **Add at midpoint / Split at %**, **Divide into N equal segments**, and **Divide every N mm**. Percentage defaults to the midpoint. From A/B counts toward the opposite endpoint. From center uses signed percentages of the whole edge: 0% is its midpoint, negative goes toward A, positive toward B. Repeated spacing from center inserts the midpoint and repeats toward both ends. Equal divisions cover the whole edge, so their positions do not depend on origin. Spacing retains shorter end remainders. All modes preview without changing the saved document and preserve cubic shape. A division is one undo entry. Limits are 1,000 resulting segments and a minimum 0.001 mm per segment; endpoint duplicates and invalid or over-dense entries are rejected.

Drafts and geometry drags auto-pan within 32 screen pixels of the canvas border, up to 300 pixels/second. Only view translation changes; the fixed draft anchors, original geometry and scale stay unchanged. The active pointer preview is recomputed under the new view. Auto-pan pauses during numeric input and dialogs, and stops when the pointer leaves the canvas or the operation ends.

## Architecture

`document/` defines schema version 9 and immutable operations. `geometry/` is pure TypeScript, independent of React and the DOM. `editor/` owns SVG interaction, transient previews, snap resolution and Zustand history. `editor/commands.ts` lists implemented commands; typed bindings attach viewport/dialog callbacks without storing mounted React state globally. `editor/geometryCommands.ts` routes shared edits through the existing immutable document operations. `editor/snapResolver.ts` combines geometry, guide and grid candidates; `editor/movement.ts` owns snapped vertex/group translation. Field entry and pointer previews stay local until the corresponding command commits. `persistence/` validates snapshots and serializes IndexedDB document/settings writes. `ui/` contains Mantine property controls; `app/` contains the shell, theme and semantic drawing colors.

Schema version 9 supports straight and cubic Bézier segments, annotations, persistent construction guides, and versioned pattern pieces with ordered stitching outlines, internal paths, metadata, sewing roles/attachments, seam allowance settings and rigid placement frames. Versions 1–8 are validated and explicitly migrated on import/open, with missing collections added only where appropriate; the stored record is updated on the next save. Unknown versions, unsupported fields, invalid marks, invalid guide IDs/positions and invalid curve controls fail validation without modifying the current document. Guide operations are immutable document edits with undo/redo; viewport and ruler state are not stored in the document. Shared endpoint IDs preserve adjacency. Geometry commits are validated before entering history. Preview frames never enter history or autosave.

Dependency setup follows the [Mantine Vite guide](https://mantine.dev/guides/vite/) and the current [react-resizable-panels API](https://github.com/bvaughn/react-resizable-panels). Resolved versions are pinned in `package-lock.json`. Export/PWA dependencies will be added when those milestones are implemented.

## Piece topology and transforms (M2.1)

Select an edge of a valid, isolated closed path, open **Piece actions → Create piece from closed path…**, enter a name and choose **Create piece**. This deliberate conversion creates a named piece; closing a drafting path alone never converts it. Click a piece's filled area or an edge to select the entire piece; Shift-click and box selection support several pieces. Drag, exact **Move…**, arrow nudges, Shift axis lock and Alt snap bypass reuse the movement controls. Each completed edit creates one undo entry.

Piece conversion follows the actual shared endpoints in either traversal direction, independently of generated point/segment ID order. Straight and cubic paths, including already split edges, retain their geometry and IDs. Regression coverage includes every combination of rectangle point-ID order and stored edge direction, legacy v5/v6 migration, and an actual UI-drawn rectangle whose IDs previously triggered `Outline edges must be connected in order.`

Use **Piece actions**, in the canvas action bar or the piece right-click menu, for rename, move, rotate, duplicate, both mirror axes, lock and hide. Selecting an individual piece edge/vertex resolves these actions to its parent; it no longer disables transforms just because the whole outline is not highlighted. A closed drafting path must be explicitly converted first; the menu explains this and offers named creation instead of showing unrelated disabled transforms. Hidden/locked pieces have Show/Unlock recovery entries in Piece actions.

Menus shift within an 8 px viewport margin before limiting their height, then scroll vertically. All context and toolbar dropdowns use the same Mantine settings; geometry and viewport transforms are unaffected. Chromium checks verified both a 900 × 480 right-click menu and a 390 × 700 touch-emulated menu fit inside the viewport. Desktop scrolling to the last recovery action and touch-emulated rename both passed.

Open **Properties** for piece bounds, width/height, world X/Y, rotation, mirrored status, name, size, fabric, cut quantity, on-fold/mirrored-pair flags, notes and an optional version. **Save piece properties** commits the fields together. The piece list lets you select, lock/unlock and hide/show every piece, including recovering hidden pieces. Locked pieces remain visible and snappable but cannot change geometry. Hidden pieces have no canvas geometry, hit targets or snaps, and are excluded from Select all and Fit all; hiding never deletes their geometry or metadata.

Bounds and rotation follow the live transform preview and return to their saved values on Cancel. Selecting several pieces shows their combined bounds and each piece's orientation/status. The single-piece metadata form appears only for one selected piece or its selected child geometry.

Closed Properties dropdowns do not block canvas shortcuts. Space-drag pans the view without moving the selected piece, and Undo works after returning focus to the canvas. Open menus, dropdowns, dialogs and text fields retain shortcut precedence.

Select **Edit points**, press **E**, or double-click a piece to select individual edges/vertices while retaining the parent piece identity. Box selection in this mode selects only individual edges of that parent; clicking another piece exits the previous parent's edit mode. **Select pieces** provides an explicit touch-accessible exit. **V**, Escape when idle, or selecting the piece from its Properties list returns to whole-piece selection. Existing length anchors, curve controls and straight/cubic split operations preserve shared endpoint IDs and ordered outline membership. Splitting inserts a fresh edge reference in the correct traversal direction; reshaping carries attached controls and shared internal endpoints.

The shared **Piece actions** menu is available with Properties hidden and inside Properties. It offers **Rotate selected pieces…**, **Duplicate pieces**, **Mirror left/right**, and **Mirror top/bottom**. Rotation previews live; Enter or Apply commits once, while Escape/Cancel discards it. Rotation and reflection use the center of the combined selection bounds, preserving the arrangement of multiple pieces. Duplication offsets independent copies by 10 mm in each world axis and gives pieces, points, segments and internal paths fresh IDs. **Fit selection**, also **F**, changes only the viewport. No scaling or resize handles are offered; imported scaled/sheared placement frames are rejected because they change physical dimensions.

To attach an internal path, select its connected loose edges, choose **Internal path parent** in Properties, and choose **Attach selected loose path**. Open and closed paths remain separate from the stitching outline. They follow whole-piece movement, rotation, reflection and duplication. This attachment is explicit; spatial overlap alone does not attach standalone marks or construction lines. Internal-path roles and attached sewing marks are available in M2.2 below. Nonzero derived cut contours remain M3 work.

Attachment selects the entire parent piece and returns to Select mode, so the next exact move carries its outline and attached path together. Locked/hidden parents, already owned edges, marks and empty selections disable attachment. Disconnected or branched paths report an error without changing geometry, selection or history.

Schema v7 pieces have their own `version: 1`, ordered `{segmentId, reversed}` stitching references, internal paths, metadata, lock/visibility and an accumulated rigid affine transform. World-mm points and curve controls contain the transformed geometry; the saved frame records placement and must not be applied a second time by rendering/export. Stitching outlines close by shared point identity and use clockwise winding in the downward-positive Y coordinate system. Reflection reverses traversal without changing segment IDs or curve shape. Signed cubic area uses exact polynomial integration; areas at or below `1e-8 mm²` are degenerate. Intersection checks use the existing `1e-7 mm` contour tolerance and `1e-6 mm` shared-endpoint comparison. Invalid topology, repeated ownership, unsupported versions and out-of-range coordinates reject the entire operation.

Versions 1–6 migrate explicitly. Existing v5/v6 identities gain ordered outlines, empty internal paths, identity frames, metadata defaults and unlocked/visible status. Unconverted loops, loose open paths, point modes and standalone marks retain their geometry and IDs. Opening a legacy saved record does not rewrite it until a save.

## Sewing roles, markings and metadata (M2.2)

Select a piece, open **Properties → Sewing roles and marks**, and choose a **Sewing edge**. Its role can be **Seam / stitch**, **Hem**, **Raw edge** or **On fold**. The ordered source loop remains the canonical stitching outline. A fold edge defaults to zero allowance and sets the piece's on-fold metadata. Nonzero cut offsets are derived by M3.1; no allowance is simulated with stroke width.

Open and closed internal paths have **construction, dart, fold, stitch or placement** roles, different dash patterns and semantic colors. Each has independent Show and Export checkboxes. Hiding removes its canvas geometry, hit targets and snaps while retaining the document data; an export-enabled hidden path can still appear in the sewing SVG. Construction paths never join the outer boundary. A path with the dart role is a drawn path; **Add dart** creates an editable sewing object.

**Add notch** opens a draggable live preview. Enter a distance in mm from the stored edge's A endpoint, or its normalized arc fraction, and choose single, double, V or T style and depth. Fractions follow the referenced edge as it changes length. Splitting that edge migrates each notch to the correct child using arc length, including cubic splits. Unrelated splits and edits preserve its segment identity. The inspector lists each notch for editing or deletion.

**Add dart** creates a symmetric two-leg internal dart defined by a local center, angle, total intake and perpendicular depth. The legs and apex are calculated from these dimensions, and the canvas shows intake/depth labels. Edit its list entry to preview changes. It leaves the stitching loop intact. Advanced edge darts, closing, pivoting and trueing remain later work. Sewing dialogs use explicit mm, Apply or Enter in a numeric field commits one history entry, and Cancel or Escape discards the preview. Invalid input cannot replace the committed document.

**Add attached grainline / fold mark** creates an editable mark in the piece's rigid coordinate frame. Optionally choose an outline edge to place the mark at its arc midpoint and follow its tangent. Attaching a fold mark also designates that edge On fold. Edit position and angle for piece-frame marks, and length, label and text size for either attachment, through its list entry. Edge-attached marks follow the edge position and tangent. To convert a legacy grainline/fold annotation, select it, choose **Sewing mark parent**, expand that piece's sewing controls and choose **Attach selected legacy mark**. Conversion preserves its text and size; piece attachment preserves world direction even on reflected pieces. Other free annotations retain their existing editors.

Designate a straight On fold edge to enable **Mirror across fold edge** or **Unfold across fold edge**. Mirror transforms the piece around the actual edge. Unfold reflects and welds both halves into one editable stitching loop, removes the shared fold boundary, carries internal paths, roles, notches, grainlines and darts into the full piece, and clears the on-fold/mirrored-pair cutting flags. Fold symbols become interior piece-attached marks. Unfold rejects curved fold axes, invalid/self-overlapping results and notches on the disappearing fold boundary with an explicit error, preserving the original half-piece. Move or remove those fold notches first. Cut geometry derives from the resulting loop using the piece allowance settings.

**Export sewing SVG** exports vector stitch geometry in physical mm with optional sewing marks, internal paths and piece metadata. Internal export flags are respected. Metadata includes name, size, fabric, cut quantity, on-fold/mirrored-pair flags, notes and version; long notes wrap and XML text is escaped. Open the SVG in a viewer to print metadata when enabled. This is a sewing drawing export; calibrated actual-size PDF and A4 tiling remain M3.3, and derived cut-contour export remains M3.2. Printer scaling and physical output have not been verified.

**Properties → Shapes → Ellipse…** drafts a numerically sized ellipse using four editable cubic arcs. Width and height are in mm; use equal values for a circle. Preview and cancellation follow the other sewing dialogs. The cubic approximation's maximum radial error is below 0.028% of the radius. No extra permanent toolbar tool is added.

Schema 8 stores sewing records under each piece, validates ownership and unique record IDs, and explicitly migrates validated schema 7 documents without inventing attachments. All fields survive JSON and IndexedDB reopen. Duplicate creates fresh record IDs and remaps segment/path attachments; move, rotate and mirror preserve piece-local sewing geometry.

## M1.3 curve editing

Curve Properties offers Start/End active point selection and Corner, Smooth, and Symmetric modes. Only the active point's arms are shown. Smooth point is available in Properties and the edge context menu, targeting the nearest endpoint. Convert to straight removes a segment's controls. Branch points with more than two incident edges reject linked modes.

Line and Polyline place straight segments, including when the pointer or finger drifts while pressing an anchor. Their ghost preview and committed geometry stay straight; implicit drag-created tangents have been removed. To create a curve, finish the path, choose Curve (C), and drag an edge or its handles. Existing saved curves and point modes remain supported. Finish or closing a polyline commits the whole path as one history entry; Escape and pointer cancellation discard the draft. An active draft suppresses the long-press/context menu so it cannot discard the unfinished path. Measurements distinguish read-only arc length from chord; splitting uses arc distance.

Schema v7 retains the optional point modes introduced by v6; missing modes mean Corner. Imports validate v1–v6 before migrating, preserving geometry and leaving stored source records untouched. Unknown schemas and invalid modes are rejected.

Invalid closed-contour edits show a warning and cannot commit. Seam offset feasibility is checked during geometry previews when allowance settings are present; unresolved cut contours block commits. Chromium regressions cover straight Polyline finish/close with anchor drift, exact dimensions, cancellation, undo/redo, real touch-event movement, and explicit Curve bending after placement. Broader active-point/Alt/handle interactions, physical touch devices and all zoom levels still need acceptance.

## Non-destructive seam offsets (M3.1)

Select a pattern piece and open **Properties → Seam allowance…**. Enter a width in canonical mm, choose **miter / round / bevel**, and set the miter limit from 1 to 20. The orange cut contour previews immediately around the unchanged stitching outline. **Apply seam allowance** or Enter commits one undo entry. Escape/Cancel discards settings and previews. **Outline visibility → Stitch / Cut / Both** changes only the view, without history or autosave. Hidden pieces hide their cut contours; locked pieces cannot change allowance settings. Cut contours are derived and have no editing hit targets.

Choose **Allowance edge**, enable **Override edge width**, and enter that edge's width in mm. Disable the override to inherit the uniform width. An **On fold** sewing edge inherits 0 mm unless explicitly overridden. Overrides follow edge splitting, duplication and mirror/unfold operations through the existing sewing records. Widths support 0–1000 mm. Miter extension is limited to the configured multiple of the larger adjacent width, with bevel fallback. Round joins use circular arcs when adjacent widths match; unequal-width round joins use a bevel transition. Concave corners use the intersection of adjacent offset lines.

The pure TypeScript engine retains exact source lines and cubic controls. It derives a closed polygon in mm without SVG stroke expansion. Cubics subdivide until their control hull lies within 0.005 mm of the finite chord and the derivative control cone bounds normal displacement error to 0.01 mm. Derived curve offsets use a conservative 0.05 mm tolerance away from deliberate corner joins; round-join chord sagitta is at most 0.005 mm. This is polygonal cut geometry, not an exact cubic offset. Unit fixtures measure mixed cubic/line distances and a closed four-cubic circle against the 0.05 mm bound.

Both windings, concave corners and fold edges are supported. Unresolved cusps, segment reversals, self-crossings, degenerate outlines, coordinate overflow and subdivision/work-limit exhaustion return an explicit error and preserve the committed source geometry and history. Complex offsets that would require trimming loops or creating multiple contours are rejected rather than repaired automatically. There are no holes or negative/inward allowances in this milestone. Source edits recalculate deterministically without a cache; invalid source previews warn and cannot commit.

Schema v9 adds optional validated piece allowance settings. Explicit v8→v9 migration preserves all source geometry, sewing overrides and IDs, and old pieces default to zero allowance without adding cut contours to saved data. Unknown or malformed schemas remain rejected. Only committed settings persist; cut vertices never enter JSON, IndexedDB or undo snapshots. The existing **Export sewing SVG** still exports the stitching drawing; exporting derived cut layers belongs to M3.2, and PDF calibration/tiling belongs to M3.3.
